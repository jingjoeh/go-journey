# Validation Exercises

- [ ] Build a minimal, idiomatic example using the standard library where practical.
- [ ] Write tests for the ordinary case and at least three boundaries.
- [ ] Inject a relevant failure and explain the observed behavior.
- [ ] Consider concurrent calls, cancellation, repeated execution, and resource cleanup.
- [ ] Add the minimum telemetry needed to diagnose a production problem.
- [ ] Compare two designs and write down the decision forces.
- [ ] Review the result using `docs/code-review-checklist.md`.
- [ ] Explain the topic aloud in five minutes without reading notes.

## Reflection

What surprised you? Which assumption failed? What evidence would raise your confidence by one level?
