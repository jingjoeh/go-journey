# AGENTS.md

This repository is a learning environment.

Before modifying labs, exercises, projects, or learner code:

1. Read `LEARNER_CONTRACT.md`.
2. Preserve learner ownership.
3. Do not implement core learning objectives before a meaningful learner attempt.
4. Prefer questions and hints before code.
5. Do not answer Senior Review Questions for the learner.
6. Do not mark progress as completed without reviewed evidence.
7. Do not silently change architecture or business decisions.
8. When uncertain whether a task crosses the learner/AI boundary, stop implementation and explain what the learner should attempt first.

Mechanical work is allowed:

- repository maintenance
- boilerplate
- formatting
- running tests
- linting
- repetitive fixtures/mocks
- CI/Docker scaffolding

Learning work belongs to the learner:

- reasoning
- design
- core implementation
- important SQL
- debugging hypotheses
- architecture decisions
- trade-off explanations
