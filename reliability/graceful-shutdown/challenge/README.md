# Graceful Shutdown Challenge

Design and implement a production-shaped use of graceful shutdown.

## Constraints

- State requirements, invariants, and non-goals first.
- Cover at least one partial failure and one concurrency or repetition scenario.
- Add tests that protect behavior rather than implementation details.
- Include operational signals and a short trade-off record.
- Do not inspect someone else's solution before documenting your own attempt.

Use the senior questions in the parent README and the repository code-review checklist.
