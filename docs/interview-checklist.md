# Interview Practice Checklist

- [ ] Clarify the question and state assumptions before solving.
- [ ] Explain the simplest correct approach before optimizing.
- [ ] Name time, space, operational, and consistency trade-offs.
- [ ] Test with ordinary, boundary, invalid, and concurrent cases.
- [ ] For Go, discuss ownership, error semantics, cancellation, races, and leaks.
- [ ] For databases, discuss schema, indexes, transactions, isolation, and query evidence.
- [ ] For APIs, discuss contracts, idempotency, pagination, limits, and compatibility.
- [ ] For system design, quantify load and identify bottlenecks and failure modes.
- [ ] For behavioral answers, use situation, action, result, and learning.
- [ ] End by identifying what you would validate with real data.

After each mock, record one strong behavior, one correction, and one focused drill. Avoid collecting dozens of questions without practicing aloud.
