# Project Progression

The projects combine modules into increasingly production-shaped systems. Build them in order, but revisit design choices as your skills improve.

For each milestone, define the user outcome, invariants, failure behavior, tests, and operational evidence before implementation. Keep an architecture decision record for choices that are costly to reverse.

| Project | Primary growth target | Suggested exit review |
|---|---|---|
| 01 — Task API | Correct, idiomatic service fundamentals | API and code review |
| 02 — Order Service | Data integrity and production patterns | Failure and concurrency review |
| 03 — Production Backend | End-to-end senior ownership | Production-readiness review |
